# UX46's working notebook

Use the existing UX46 mark with midnight `#090D14`, violet `#AD98F5`, and soft
white `#F3F3F6`. Muted blue-gray supports body text; paper `#EAE2D6` is an
occasional annotation color. The product's light theme remains a first-class
option even though the documentation artwork has a dark ground.

The artwork in `ux46-workshop-1.svg` is an original editable vector illustration,
not a screenshot or evidence of a shipped feature. It reuses the project's own
logo geometry from `app/console/brand/ux46-icon-1.svg`. No private workspace,
conversation, or third-party font is embedded. Assets here share the repo's MIT
license.

Use generous spacing and one useful visual rather than a pile of badges. Keep
essential words in Markdown as well as artwork. At phone width the image is a
visual introduction; nobody should have to read miniature illustration labels
to install the app. Version delivered artwork instead of replacing its filename.

For writing and code explanations, see [vibe-craft](../../skills/vibe-craft/SKILL.md).
