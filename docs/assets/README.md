# UX46's visual direction

The current hero is `ux46-workspace-2.png`, a supplied concept illustration used
without alteration. It combines near-black depth, luminous violet, strong white
typography and layered interface panels. Fine connections and restrained light
suggest a workspace that can grow around its owner. Keep essential instructions
in Markdown; miniature panel labels are atmosphere, not onboarding instructions.

The concept is not a product screenshot, a working API example, or evidence that
every pictured control has shipped. The README labels it accordingly. The image
contains no visible private workspace or account details. The supplied PNG is
preserved byte for byte, including its embedded AI-generation provenance.

`ux46-workshop-1.svg` is the previous illustration, retained as a versioned asset.
Its flat panels and paper-note treatment are not the direction for new artwork.
The existing UX46 logo remains in `app/console/brand/`; this hero update does not
change the application's palette or light theme.

Use generous spacing and one useful visual rather than a pile of badges. Inspect
GitHub at desktop and phone widths. Version delivered artwork instead of
replacing its filename. For writing and code explanations, see
[vibe-craft](../../skills/vibe-craft/SKILL.md).
