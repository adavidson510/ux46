Use the project's canonical Session Vault record for meaningful progress,
blockers and human needs. Read `python3 tools/session_vault.py checkpoint --help`
for the version-checked contract. Set ATLAS_REGISTRY to UX46_HOME/registry.json.
Keep runtime activity separate from an agent's reported progress. A blocked
state needs a concrete next action. Never notify other people without authority.
